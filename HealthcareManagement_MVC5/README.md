# Healthcare Management System

Legacy ASP.NET MVC 5 / Web API 2 application targeting .NET Framework 4.8.
SQL Server + Entity Framework 6. No ASP.NET Core / .NET Core.

## Main business flows
- Patient registration and profile management
- Provider registration and provider lookup
- Appointment scheduling, rescheduling and cancellation
- Eligibility and insurance verification
- Encounter creation and clinical-service recording
- Medical claim creation and claim status tracking
- Claim validation and adjudication workflow
- Payment/claim settlement tracking
- Patient billing and outstanding balance
- Search, dashboard and operational reporting
- Audit/history tracking

## Architecture
- Presentation: ASP.NET MVC 5 + Web API 2
- Business: Services
- Data: Entity Framework 6 / SQL Server
- Database: SQL Server
- API style: REST/Web API 2

This is a reference/portfolio implementation skeleton. Replace connection strings and secrets before deployment.
