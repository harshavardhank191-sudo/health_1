# Insurance Management System

Legacy ASP.NET MVC 5 / Web API 2 application targeting .NET Framework 4.8.
SQL Server + Entity Framework 6. No ASP.NET Core / .NET Core.

## Main business flows
- Customer/member registration and profile management
- Insurance product and plan setup
- Quote creation and premium calculation
- Policy application submission
- Underwriting review and approval/rejection
- Policy issuance and policy document tracking
- Premium payment and payment history
- Policy renewal and cancellation
- Endorsement/change request processing
- Claim registration and document capture
- Claim validation, assessment and settlement
- Fraud/risk review status tracking
- Agent/customer service case management
- Search, dashboards and operational reporting
- Audit/history tracking

## Architecture
- Presentation: ASP.NET MVC 5 + Web API 2
- Business: Services
- Data: Entity Framework 6 / SQL Server
- Database: SQL Server
- API style: REST/Web API 2

This is a reference/portfolio implementation skeleton. Replace connection strings and secrets before deployment.
